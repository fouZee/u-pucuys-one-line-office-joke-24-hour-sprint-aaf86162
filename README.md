One-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty — a single original joke about office life, delivered by a small deterministic program.

## The joke

> I set my out-of-office reply to 'per my last email', so the passive aggression keeps working while I'm on holiday.

The setup is the most passive-aggressive phrase in office email; the punchline automates it — the snark keeps working while its owner is on holiday.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=./output node main.ts`). Node 22+ runs the TypeScript directly; no dependencies, no network, deterministic output.
